# Pulse v0.3.0-beta

Pulse continues as a local-first Windows diagnostics platform.

This release makes **Pulse MCP** production-ready for AI clients (Cursor, Claude Desktop), with Settings / Diagnostics productization, installer packaging, and the frozen MCP tool surface from milestones M2–M7.

## Highlights

### Pulse MCP (first-class)

- Official Model Context Protocol server (**PulseMCP** `0.7.0`)
- Observation tools only — structured JSON, no model-authored reports
- Frozen milestones M2–M7:
  - **system.*** health tools + live resources
  - **process.*** list / search / details
  - **timeline.*** list / search + live resource
  - **diagnostics.snapshot** / **service.status**
  - **report.export** (json / csv / html / pdf / markdown) — metadata only
  - Productization (Settings, Diagnostics, installer, registration)

### AI Integration (Settings)

- Dedicated **Settings → AI Integration** page
- Opt-in MCP policy (`%LOCALAPPDATA%\Pulse\mcp\policy.json`)
- Start Pulse MCP status heartbeat with Pulse
- One-click **Cursor** global registration (safe merge + backup)
- Claude Desktop registration provider; ChatGPT reserved for later
- Open logs / MCP documentation from Settings

### Diagnostics → MCP

- Live status from `status.json` heartbeats
- Version, uptime, requests, latency, subscriptions, clients, memory, namespaces

### Installer & runtime

- `PulseMCP.exe` + private `runtime\node.exe` + `mcp\` via `package_pulsemcp.ps1`
- End users do **not** need a system Node.js install
- Uninstall cleans Pulse-owned AI client registrations only
- Named-pipe max instances raised **4 → 8**

## Fixed / hardened

- MCP policy hard-refuse when disabled (`POLICY_DISABLED`)
- Config backup + JSON validation before Register writes
- Unregister only when Pulse created the client entry

## Known limitations

- Not code-signed (unless ops ADR changes)
- ChatGPT MCP registration is not available yet
- MCP Streamable HTTP (M8) is not in this release
- Some Inventory fields remain hardware/OS dependent (`Not supported` / `unavailable`)

## Install

1. Download **`Pulse-Setup-0.3.0-beta-windows-x64.exe`**
2. Run as administrator (UAC)
3. Open **Settings → AI Integration** → Enable Pulse MCP → Register for Cursor
4. Restart Cursor if it was already open
