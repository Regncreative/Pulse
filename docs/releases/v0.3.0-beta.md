# Pulse v0.3.0-beta (draft)

**Train:** R2 Timeline Intelligence (flagship)  
**Status:** Draft release notes — R2 frozen; packaging/signing not part of this close.  
**Close evidence:** [architecture/archives/r2-validation-report-2026-08-02.md](../architecture/archives/r2-validation-report-2026-08-02.md)

Builds on Wave A (R0–R1) with a flagship Timeline: incidents, RCA hints, Event Viewer–parity details, export, search, and expanded Event Intelligence.

## Highlights

### Timeline Intelligence
- Incident collapse for documented correlation rules (no fabricated groups)
- Root-cause hints (possible cause, confidence, related events, next step) only when a rule matches
- Details panel: Wevtapi system fields + lazy Raw Event XML
- Event links: previous/next related, same provider / process / incident
- Metadata badges: Live, Bookmarked, Pinned, Correlated, Generated by rule (truthful only)

### Filters, search, library
- Severity, source, category, provider, Event ID, process, date range, keyword
- Case-insensitive search across provider, Event ID, computer, message, XML (when loaded), process, PID
- Bookmarks, pins, and saved searches persist across app restarts

### Export
- JSON **v2** and **CSV** preserve applied filters, bookmark/pin flags, incident membership, and metadata columns

### Performance
- In-memory retention cap up to **100,000** events (Settings presets)
- Virtualized list (`SliverList`) with stable `eventId` keys; raw XML loaded on demand
- Incident engine scaled for 100k synthetic load (automated gates)

### Event Intelligence
- Rule catalog expanded from **38 → 68** (+30 Microsoft-documented Event IDs)
- Inventory: [architecture/38-timeline-intelligence-rules-inventory.md](../architecture/38-timeline-intelligence-rules-inventory.md)
- Correlation rules: [architecture/37-timeline-correlation-rules.md](../architecture/37-timeline-correlation-rules.md)

## Explicitly deferred
- Wevtapi subscribe resume bookmarks (documented)
- Multi-step display recovery chains without cited Event IDs
- Structured Version / Qualifiers / Provider Guid columns (available via Raw Event XML)
- Theme redesign work (out of R2)

## Install (when packaged)
1. Download **`Pulse-Setup-0.3.0-beta-windows-x64.exe`** (when published)
2. Run as administrator (UAC)
3. Open Timeline; optionally raise max stored events under Settings → Timeline

## Known limits
- Not code-signed (unless ops ADR changes)
- Incidents are recomputed from retained events (not separately persisted)
- Security-channel rules only when the Security log is readable
- Raising retention to 100k increases RAM with average message size
