# Pulse v1.1.0 — Local AI Assistant

Pulse v1.1.0 introduces the new local AI-powered Pulse Assistant.

## What's New

### Local AI Assistant

- Local LLM support through Ollama and LM Studio
- Analyze your system using local AI
- CPU, memory, GPU, storage, network, process and event diagnostics
- Read-only diagnostic tool access
- No cloud AI required
- No arbitrary command or system modification capabilities

### Background & Tray

- Keep Pulse running in the system tray
- Background monitoring
- Local Windows notifications for critical system conditions
- Quick access to Pulse sections from the tray

### System Health

- Semantic utilization colors:
  - Green: 0–49%
  - Yellow: 50–69%
  - Orange: 70–89%
  - Red: 90–100%

### Assistant UX

- Assistant integrated into the main sidebar
- Manual local AI/model selection
- Streaming responses
- Diagnostic tool activity
- Session-only conversation history

### Improvements

- Improved switch interaction
- Improved navigation
- Improved System Health visualization
- Various stability and UX improvements

## Downloads

**Portable ZIP**

`Pulse-1.1.0-windows-x64.zip`

Pulse remains local-first. Diagnostic data is processed locally and the Assistant does not have permissions to execute commands or modify the system.

## Upgrade from 1.0.0

1. Install **`Pulse-Setup-1.1.0-windows-x64.exe`** (UAC)
2. Confirm Diagnostics → App / Service show **1.1.0**
3. If you use MCP: **Settings → AI Integration → Unregister → Register**
4. Fully quit and reopen Cursor / Claude Desktop if MCP configs changed
