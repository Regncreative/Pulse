# Pulse v0.2.1-beta

Pulse continues to evolve into a local-first Windows diagnostics platform.

This release introduces the new Inventory Engine, major Timeline Intelligence improvements, enhanced reporting, performance optimizations, and significant UI refinements across the application.

## Highlights

### Inventory Engine (New)

A brand-new Inventory module has been added.

Browse detailed information about:

- Motherboard
- BIOS
- CPU
- Memory
- Storage
- Network adapters
- USB devices
- PCI devices
- Displays
- Audio devices
- Bluetooth
- Battery
- Installed software
- Drivers
- Windows services

Inventory data is collected on demand, cached for fast navigation, and powers the new reporting system.

### Timeline Intelligence

The Timeline has been significantly expanded with:

- 68 built-in intelligence rules
- Incident correlation
- Advanced filtering
- Bookmarks & saved searches
- JSON v2 and CSV export
- Improved event details
- Support for very large timelines (100,000+ events)

### Reports

Reports have been redesigned and expanded.

Export:

- JSON
- CSV
- HTML
- PDF

Reports now use the Inventory Engine where applicable, providing richer and more accurate system information.

### Performance & Stability

- Inventory domain caching
- Faster navigation between pages
- Improved IPC communication
- Reduced unnecessary rebuilds
- Long-duration soak testing
- Various performance optimizations and bug fixes

### UI Improvements

- Redesigned Inventory browser
- Responsive header actions
- Better Timeline filters
- Improved Diagnostics layout
- Theme improvements
- Numerous UI polish fixes

### MCP Foundation

The internal architecture is now prepared for upcoming Model Context Protocol (MCP) support.

No AI provider is embedded into Pulse.

Future releases will allow Pulse to connect with MCP-compatible clients such as Cursor, Claude Desktop, and other AI tools.

## Fixed

- Inventory rendering issues
- Theme switching improvements
- Timeline rendering improvements
- Export improvements
- Layout fixes
- Various stability and performance issues

## Known limitations

- Some hardware information depends on Windows APIs and may appear as Not supported on certain hardware.
- Bluetooth and Battery availability depends on the current machine.
- MCP integration is not enabled yet.

## Install

1. Download **`Pulse-Setup-0.2.1-beta-windows-x64.exe`**
2. Run as administrator (UAC)
3. Open Inventory to browse hardware and software catalogs
