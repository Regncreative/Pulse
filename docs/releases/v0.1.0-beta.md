# Pulse v0.1.0-beta

**See what Windows is really doing.**

First public **pre-release** of Pulse — a modern, read-only Windows diagnostics platform. Pulse turns Event Log activity into a human-readable Timeline, with System Health and local Diagnostics, over a local named-pipe IPC to a native Windows service.

> Observation only. No injection. No hooks. No telemetry. No cloud.

---

## Highlights

- **Timeline** — historical snapshot on connect (default 100 events), then live Event Log monitoring
- **Deterministic startup** — `ServerHello` → `TimelineSnapshot` → `StartLiveMonitoring`
- **Human-readable events** — plain language first; technical detail and raw XML on demand
- **System Health** — CPU, memory, GPU, disk, and network cards (Task Manager–aligned where APIs allow)
- **Diagnostics** — service/IPC snapshot, inject test event, local export zip
- **Installer** — Inno Setup UAC installer; registers and starts PulseService automatically (no PowerShell)
- **Privacy** — local-first; no accounts, analytics, or ads

---

## Requirements

- Windows 10 (1809+) or Windows 11 (x64)
- Administrator approval (UAC) for install / service registration
- Visual C++ runtime (bundled / installed by Setup when needed)

---

## Installation

1. Download **`Pulse-Setup-0.1.0-beta-windows-x64.exe`** from this pre-release.
2. Run the installer and accept the UAC prompt.
3. PulseService is installed and started automatically.
4. Pulse launches; complete or skip the welcome screen.

Uninstall via Windows **Apps & features** or the Start Menu uninstaller (service is removed with the product).

---

## Known limitations

- **System Event Log channel only** in this milestone (Application / Security channels are roadmap)
- **ETW / WMI** not included yet (planned for later milestones)
- **Code signing** may be pending — SmartScreen may warn on first run of unsigned builds
- **Pre-release quality** — APIs and UI may change before `v0.1.0` stable
- Health “top network” process ranking is limited under the Windows service account (by design, for service stability)
