# Pulse v0.2.0-beta

UX/UI redesign milestone. All System Health, Timeline, and Diagnostics capabilities remain; the interface is reorganized for clarity.

Built from commits `6d3a539` … UX redesign series on top of `0.1.3-beta`.

## Highlights

### Design system and themes
- Light / Dark / System themes with Blue, Green, Purple, Orange, and custom accents
- Shared `PulseSection`, metric rows, skeletons, and dialogs

### System Health
- Detail panels use collapsible sections (Overview, Processes, History, …) with remembered expand state
- Dashboard customize: show/hide and reorder widgets; compact density

### Settings
- Categorized settings center (Appearance, System Health, Timeline, Diagnostics, Performance, Privacy, Updates, Developer)
- Units (binary/decimal), temperature C/F, clock format, text size, animation speed
- Settings JSON export/import

### Navigation
- Reports page in the sidebar
- Command palette (**Ctrl+K**) for navigation, theme, and Health panels
- Keyboard **Ctrl+1…5** page switching

### Reports
- Export Health snapshot, Timeline, Diagnostics, and Hardware inventory as JSON, CSV, HTML, or PDF

## Install

1. Download **`Pulse-Setup-0.2.0-beta-windows-x64.exe`**
2. Run as administrator (UAC)
3. Open Settings → Appearance to try Light theme / accent colors

## Known limits

- Not code-signed
- Full i18n and tray/startup integration not in this beta
- Installed-software / full driver inventory reports not included (no new collectors)
