# Pulse v1.0.0

First **stable** release of Pulse — a read-only Windows diagnostics platform.

## Highlights

- **Timeline** — human-readable Windows Event Log events, live subscribe, search, filters, date presets
- **System Health** — CPU, memory, GPU, disk, network with live charts
- **Inventory** — motherboard, devices, drivers, services, installed software (read-only APIs)
- **Reports** — export JSON / CSV / HTML / PDF locally
- **Diagnostics** — PulseService identity, IPC, collectors, PulseMCP status
- **AI Integration** — optional PulseMCP (bundled private Node; no system Node.js)

## Stable vs beta

- Version stamp is **`1.0.0`** (no `-beta` suffix in UI, service, or installer)
- Recommended install path remains the **Setup.exe** (PulseService required)
- ZIP / payload folder is still **not** a true portable SKU — see [40 — Portable ZIP vs Windows Service](../architecture/40-portable-vs-service.md)

## Upgrade from 0.3.x-beta

1. Install **`Pulse-Setup-1.0.0-windows-x64.exe`** (UAC)
2. Confirm Diagnostics → Service shows **Running** / **1.0.0**
3. If you use MCP: **Settings → AI Integration → Unregister → Register**
4. Fully quit and reopen Cursor / Claude Desktop

The Store MSIX includes **`service\PulseService.exe`** registered via `desktop6:Service` (`StartAccount=localService`) and requires Partner Center approval of the **`packagedServices`** restricted capability before resubmission. GitHub Releases still ships the full Setup.exe with classic SCM `--install-start`.

Claude Desktop installed from the Microsoft Store uses a separate config path; PulseMCP registration writes both classic and Store Claude configs. See [AI Integration](../guides/ai-integration.md).
