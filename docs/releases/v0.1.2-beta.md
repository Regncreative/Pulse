# Pulse v0.1.2-beta

Pre-release build focused on System Health accuracy and Task Manager–style presentation.

## Highlights

### System Health — Memory
- Memory Overview aligned with Task Manager Performance > Memory (Used/Total, Available, Committed, Cached, Compression, Hardware Reserved, pools, Page Faults/sec)
- Process list uses private working set (`WorkingSetPrivateSize`) with app grouping and memory-descending sort
- Memory size formatting (`X.XX GB` / MB) instead of coarse round numbers

### System Health — CPU
- Full process inventory with Task Manager–style app groups (Apps / Background / Windows)
- Collapsed rows show aggregate metrics; expand for per-PID children with icons

### System Health — GPU / Network / Overview enrichment
- Richer GPU Overview (identity, vendor, driver, engines, VRAM capacity/usage when available) via DXGI + PDH
- GPU process names resolved to real executables (not `pid_N` when known), with icons
- Network Overview expanded (adapter identity, MAC, link speed, DHCP/leases, counters, live peak/avg/util; Wi‑Fi via WLANAPI when applicable)
- Per-process network remains deferred with an explicit “not available yet” empty state (ETW milestone)
- CPU / Memory module / Disk identity overview fields from Win32 / SMBIOS / Storage IOCTLs; unsupported metrics show `—` / Not supported
- Overview SpecRow UI (label / value / description)

### Service reliability
- Fix for SCM crash on client disconnect (`0xc0000409` / joinable `std::thread` lifetime)
- ESTATS-based per-process network removed (unreliable under LocalService)

### Packaging
- Version bumped to **0.1.2-beta** across app, service, installer, and docs

## Install

1. Download **`Pulse-Setup-0.1.2-beta-windows-x64.exe`**
2. Run as administrator (UAC)
3. Confirm Connected / Live, then open System Health

## Known limits

- Not code-signed (SmartScreen may warn)
- Per-process network requires a future ETW milestone
- Some GPU telemetry (absolute power watts, Resizable BAR, WDDM/PCIe/clocks when D3DKMT unavailable) remains `—` without vendor SDKs
- System Event Log channel only for Timeline
