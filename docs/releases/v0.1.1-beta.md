# Pulse v0.1.1-beta

**See what Windows is really doing.**

Second public **pre-release** of Pulse. Builds on `v0.1.0-beta` with service reliability fixes, richer System Health (disks, top processes, icons), and layout polish.

> Observation only. No injection. No hooks. No telemetry. No cloud.

---

## What's new since v0.1.0-beta

### Service lifecycle & first-run

- In-app **Start / Stop / Restart** and **Repair / Install** for PulseService (UAC)
- Start/stop prefer the **SCM-installed** binary (`Program Files`), not only the app folder copy
- Clearer offline recovery on Timeline, Diagnostics, System Health, and welcome/first-run

### System Health

- **Multi-disk / multi-volume** listing (fixed, removable, and network volumes where safe)
- **Top Processes** rebuilt via `NtQuerySystemInformation` (works under LocalService)
- Process rows show **real Windows icons** when the executable path is known (with system-binary and letter fallbacks)
- Service fills executable paths when allowed; known SystemRoot paths for common protected binaries
- **Storage card** scrolls internally — no RenderFlex overflow with many volumes
- **CPU History** grid scales/scrolls for high core counts

### Packaging

- Installer and payload versioned as **0.1.1-beta**
- Packaging script uses a single `$Version` for zip/setup names

---

## Highlights (unchanged)

- **Timeline** — historical snapshot on connect, then live Event Log monitoring
- **Human-readable events** — plain language first; technical detail and raw XML on demand
- **Diagnostics** — service/IPC snapshot, inject test event, local export zip
- **Installer** — Inno Setup UAC installer; registers and starts PulseService automatically
- **Privacy** — local-first; no accounts, analytics, or ads

---

## Requirements

- Windows 10 (1809+) or Windows 11 (x64)
- Administrator approval (UAC) for install / service registration
- Visual C++ runtime (bundled / installed by Setup when needed)

---

## Installation

1. Download **`Pulse-Setup-0.1.1-beta-windows-x64.exe`** from this pre-release.
2. Run the installer and accept the UAC prompt (upgrades an existing Pulse install in place).
3. PulseService is installed/updated and started automatically.
4. Pulse launches; complete or skip the welcome screen.

Uninstall via Windows **Apps & features** or the Start Menu uninstaller (service is removed with the product).

---

## Known limitations

- **System Event Log channel only** in this milestone (Application / Security channels are roadmap)
- **ETW / WMI** not included yet (planned for later milestones)
- **Code signing** may be pending — SmartScreen may warn on first run of unsigned builds
- **Pre-release quality** — APIs and UI may change before `v0.1.0` stable
- Some **protected / system processes** still show a letter avatar when the path cannot be opened
- Health **top network** process ranking remains limited under the Windows service account (by design)
