# Pulse v0.1.3-beta

Pre-release completing the System Health quality milestone (GPU → Network ETW → Hardware → Timeline → Diagnostics → UX).

Built from commits `15dae7b` … `e11ce3f` on top of `0.1.2-beta`.

## Highlights

### GPU (Phase 1)
- WDDM version and PCI location via D3DKMT; PCIe link via SetupAPI when available
- Video Processing engine util; process VRAM from PDH GPU Process Memory
- Inventory-grouped GPU process list (real names/icons), sorted by GPU %
- D3DKMT temp/fan/power % / clocks when the driver returns non-zero values
- Resizable BAR and absolute watts remain **Not supported**

### Network (Phase 2)
- Overview unchanged (adapter identity, rates, Wi‑Fi)
- Per-process upload/download/total via Pulse-owned ETW session `PulseHealthNet` (ADR-009)
- If ETW cannot start under LocalService, rates stay `—` (never invented)

### Hardware (Phase 3)
- NVMe/SSD temperature and SMART health via Storage IOCTLs when Windows exposes them
- CPU package temperature / motherboard fans remain **Not supported** without public Win32 APIs

### Timeline (Phase 4)
- Multi-channel Event Log snapshot/live (System, Application, Setup, Update, PnP, Thermal, Boot; Security if readable)
- Expanded Microsoft-documented intelligence/humanizer rules (crash, power, service, update, device, storage)
- Category filters in the UI; search / severity / JSON export retained

### Diagnostics (Phase 5)
- Service executable path, build version, git commit, SHA256, SCM state
- IPC throughput; collector/ETW status; Flutter FPS / frame timings / RSS

### UX (Phase 6)
- Overflow, empty/loading states, tooltips, hit targets, Semantics, Timeline virtualization

## Install

1. Download **`Pulse-Setup-0.1.3-beta-windows-x64.exe`**
2. Run as administrator (UAC)
3. Confirm Connected / Live, then open System Health and Timeline

## Known limits

- Not code-signed (SmartScreen may warn)
- Per-process network requires a successful ETW session
- CPU package sensors and GPU watts / ReBAR remain Not supported
- Security channel often inaccessible under LocalService
