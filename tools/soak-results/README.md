# Soak result reports (JSON + Markdown)

Generated by `tools/scripts/soak_overnight.ps1` at the end of each soak.

| File | Contents |
|------|----------|
| `soak-report-<stamp>.json` | Machine-readable summary + verdict |
| `soak-report-<stamp>.md` | Human-readable summary + verdict |

**R1 status is not updated by these files.** Wave A closes only after maintainer review of a PASS (or accepted PASS WITH WARNINGS) soak plus clean-VM installer validation.

Result files in this folder are local validation artifacts (see repo `.gitignore`).
